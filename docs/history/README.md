# Historical delivery records

This directory preserves provenance from the initial design-system delivery.

- [`milestones/`](milestones/M0-inventory-review.md) contains the completed M0–M9 gate reports, milestone-specific notes, and verification evidence.
- [`bootstrap/design-baseline/`](bootstrap/design-baseline/ARTIFACT-INDEX.md) contains the approved input snapshot copied from the bootstrap handoff.
- [`bootstrap/architecture/`](bootstrap/architecture/FIRST-VERTICAL-SLICE.md) contains the completed first-slice plan and its then-open decisions.

These files explain why the repository reached its current shape. They may contain old paths, proposed statuses, one-time approval rules, or version statements. Do not treat them as current operating instructions. Use `AGENTS.md`, `docs/agents/`, current source, and current configuration for active work.
