# Release preparation

No publication is authorized. Before a coordinated first release:

1. Complete the M9 acceptance matrix and record accepted limitations.
2. Decide final package names/scope, repository identity, license and coordinated version.
3. Confirm package contents, exports, declarations, CSS assets, dependency notices and consumer bundle behavior from packed artifacts.
4. Verify browser and optional Electron consumption in user-approved environments.
5. Create provenance, changelog and publication commands for human review.
6. Obtain separate authorization for any remote creation, push and npm publication.

All accepted v1 packages should be versioned and published together. Partial publication is out of scope.
